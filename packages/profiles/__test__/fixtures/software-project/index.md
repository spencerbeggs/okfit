# Project

* [okfit](project.md) - Node.js tooling for the Open Knowledge Format.

# Subdirectories

* [modules](modules/index.md) - One Module per workspace package.
* [decisions](decisions/index.md) - Choices made and the alternatives rejected.
* [conventions](conventions/index.md) - Rules contributors and agents follow.
* [interfaces](interfaces/index.md) - Contracts others depend on.
* [references](references/index.md) - Mirrored external material.
* [runbooks](runbooks/index.md) - Repeatable operational procedures.
* [glossary](glossary/index.md) - Terms this repository uses in its own sense.
* [limitations](limitations/index.md) - Known edges of the contracts.
* [models](models/index.md) - Internal source-of-truth structures.
* [gotchas](gotchas/index.md) - States that look like one thing and are the opposite.
* [consumers](consumers/index.md) - External applications that consume this repository.
* [roadmaps](roadmaps/index.md) - Gates and the forward-looking work behind them.
* [measurements](measurements/index.md) - Dated empirical results that justified Decisions.
* [invariants](invariants/index.md) - Properties the code holds by construction.
* [incidents](incidents/index.md) - Dated production failures and the guards that now stop them.
