# Humanizer Before/After Exemplars

These exemplars adapt the humanizer skill's principles to technical user-facing documentation. Em dashes are preserved as a stylistic choice; everything else from the general humanizer guide applies.

## Promotional phrasing

**Before:** This breathtaking library serves as a testament to modern TypeScript design.

**After:** This library is a small TypeScript module for one thing: parsing OSC8 hyperlink escape sequences.

## Inflated significance

**Before:** A pivotal moment in the package's evolution arrived when we introduced layer composition.

**After:** Version 0.4 added layer composition. That changed how callers wire up the runtime.

## -ing analyses

**Before:** The resolver works by examining the environment, evaluating the relevant variables, and emphasizing the priority order across XDG, system defaults, and user overrides.

**After:** The resolver reads XDG environment variables. If a variable is unset, it falls back to the system default. The user can override either with an explicit value.

## Filler phrases

**Before:** In order to use this package, at this point in time, you would need to install it via npm.

**After:** Install via npm.

## Elegant variation

**Before:** The function returns a value. The method yields a result. The procedure produces an outcome.

**After:** The function returns a value. The function returns a value. (When you mean the same thing, use the same word.)

## Copula avoidance

**Before:** The TargetResolver service serves as the entry point for resolving publish targets.

**After:** The TargetResolver service is the entry point for resolving publish targets.

## Knowledge-cutoff disclaimers

**Before:** As of my last update, the package supported Node 20+.

**After:** The package supports Node 20+.

## Sycophantic chatbot pleasantries

**Before:** I hope this helps! Feel free to reach out if you have any questions.

**After:** (Delete it. The reader is consulting a reference, not a chatbot.)

## False ranges

**Before:** This works for everyone from beginners to experts.

**After:** This works whether you have used Effect before or not.

## Rule-of-three forcing

**Before:** The library is fast, reliable, and powerful.

**After:** The library has zero runtime dependencies and parses OSC8 in under 50 lines.

## When in doubt

Read the passage aloud. If you would not say it that way to a colleague, rewrite it.
