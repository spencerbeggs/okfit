# okfit

okfit is a pnpm monorepo of Node.js tooling for Open Knowledge Format 0.2 bundles: a spec-level core library, named configuration profiles, a CLI and an MCP server.

## Out of scope

- Editing concept bodies for the user; okfit validates, derives and scaffolds, it never rewrites prose.
- Hosting or serving bundles; a bundle is files in a repository.
